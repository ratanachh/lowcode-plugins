# @rchh/lowcode-plugin-zh-cn [![][npm-image]][npm-url]

Switch between Simplified Chinese and English for Lowcode Engine.

---

## Usage

### Register the plugin
```jsx
import { plugins } from '@rchh/lowcode-engine';
import PluginZhCn from '@rchh/lowcode-plugin-zh-cn';

// Register with the engine
plugins.register(PluginZhCn);
```

### Plugin properties & methods

No properties or methods are exposed.
